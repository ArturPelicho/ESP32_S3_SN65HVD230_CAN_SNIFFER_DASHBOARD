# How-to guides

Short, step-by-step guides for the things riders do most. New to the app? Start with
[Getting started](../getting-started.md). Looking for one setting? The
[user guide](../app-guide.md) describes every screen and option.

Throughout the app, **a tap does the main thing and a long press opens the options**.

| [Go somewhere](go-somewhere.md) | Search an address or a place, or long press the map, and go |
| [Plan a route on the map](plan-a-route.md) | Numbered waypoints along the roads, edit, save and share |
| [Ride a GPX track](follow-a-track.md) | Import a track, follow it, Nav or Track mode |
