# Choose the kind of route

![Route type page in the track box menu](../img/app/route-type.png)

Long press the track box → **Route type ›** (or Settings → Tracks → Navigation).

| Type | What it looks for |
|---|---|
| **Fastest** | Main roads at cruising speed (up to about 100 km/h) |
| **Economical** | Steady, slower roads (up to about 70 km/h): less fuel |
| **Fun** | Dirt: as many tracks and unpaved roads as your detour allows, no motorways, round the towns |

Each type keeps its own switches:

- **Avoid motorways**, **Avoid tolls**, **Avoid dirt roads**, **Go round towns**.
- **Stay on main roads**: only leaves a main road for village lanes or service roads when that
  saves more than 2 minutes and 1 km.
- **Fun: longest detour allowed**: how much longer than the fastest route you are happy to ride
  for the dirt (picked from a list).

Changing any of them recalculates the route you are following straight away. **Recalculate
this route** does it by hand.
