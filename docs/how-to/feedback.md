# Send a suggestion or report a problem

Settings → About:

- **Send a suggestion**: opens a new issue on this project, ready to fill in. Write your idea
  and send it.
- **Report a problem**: the same, with a few lines asking what happened and how to see it again.

Both add the app version, the Android version and the phone model, so a problem can be
reproduced.

Both need a free GitHub account; you see everything before it is sent.

## If the app closes unexpectedly

The next time it opens, NavExpress offers to send the error report. Choose **Send on GitHub**,
**Share another way**, or **Not now**. Nothing is sent without your tap.

You can also [open an issue](../../../../issues/new) directly, or look at the
[roadmap](../../ROADMAP.md) to see what is already planned.
